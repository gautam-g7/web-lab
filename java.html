STRING AND MATH OBJECTS IN JAVA SCRIPT

VARIOUS PREDEFINED FUNCTIONS IN A STRING AND MATH OBJECT IN JAVA SCRIPT.

1) STRING OBJECTS IN JAVASCRIPT


  • Length () : returns the number of characters , eg: "hello".length =5.

  • toUpperCase(): converts text to uppercase , eg: "hello".toUpperCase() ="HELLO".

  • toLowerCase(): converts text to lowercase , eg: "Hello".toLowerCase() ="hello".

  • charAt () : returns the character at a position , eg: "hello".charAt(1) ="e".

  • indexOf () : finds the position of a character or word , eg: "hello".indexOf("l") =2.

  • slice () : extracts part of a string , eg: "hello".slice(1,4) ="ell".

  • replace () : replaces part of a string , eg: "hello".replace("h","y") ="yello".

  • trim () : removes extra spaces at both ends , eg: "hello ".trim() ="hello".
 2) MATH OBJECTS IN JAVASCRIPT
  • Math.round(x) : rounds to the nearest integer ,eg:Math.round(4.6)->5

  • Math.floor(x) : rounds down ,eg:Math.floor(4.9)->4

  • Math.ceil(x) : rounds up ,eg:Math.ceil(4.1)->5

  • Math.sqrt(x) : finds square root ,eg:Math.sqrt(25)->5

  • Math.pow(x) : finds the power ,eg:Math.pow(2,3)->8

  • Math.abs(x) : returns absolute value ,eg:Math.abs(-10)->10

  • Math.max(x) : returns the largest value ,eg:Math.max(10,20,30)->30

  • Math.min(x) : returns the smallest value ,eg:Math.min(10,20,30)->10

  • Math.random(x): generates a random number between 0 and 1 ,eg:Math.random()

  • Math.PI : value of π ,eg:Math.PI->3.1415
